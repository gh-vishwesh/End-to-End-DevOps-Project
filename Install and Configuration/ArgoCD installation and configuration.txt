ArgoCD install and configuration
================================

1. Install ArgoCD
kubectl create namespace argocd
kubectl apply -n argocd --server-side -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml
kubectl get pods -n argocd -w            # wait until all are Running

2. Reach the UI - choose ONE:
  a) Port-forward (nothing exposed to the internet, recommended):
     kubectl port-forward -n argocd svc/argocd-server 8080:443
     open https://localhost:8080  (accept the self-signed certificate)
  b) Public load balancer:
     kubectl patch svc argocd-server -n argocd -p '{"spec": {"type": "LoadBalancer"}}'
     kubectl get svc argocd-server -n argocd     # EXTERNAL-IP column = URL

3. Log in
Username: admin
Password:
  Linux/macOS/WSL:
    kubectl -n argocd get secret argocd-initial-admin-secret -o jsonpath="{.data.password}" | base64 -d; echo
  PowerShell:
    $p = kubectl -n argocd get secret argocd-initial-admin-secret -o jsonpath="{.data.password}"
    [System.Text.Encoding]::UTF8.GetString([System.Convert]::FromBase64String($p))
Change it after first login (User Info > Update Password), then:
    kubectl -n argocd delete secret argocd-initial-admin-secret

4. Create the application namespace
kubectl create namespace k8s-project

5. Create the Application - choose ONE:
  a) Declarative (recommended, repeatable):
     kubectl apply -f "Install and Configuration/argocd-application.yaml"
  b) UI: + NEW APP
       Application Name : myapp
       Project          : default
       Sync Policy      : Automatic  (tick PRUNE RESOURCES and SELF HEAL)
       Repository URL   : https://github.com/gh-vishwesh/End-to-End-DevOps-Project.git
       Revision         : main
       Path             : Kubernetes with ArgoCD
       Cluster URL      : https://kubernetes.default.svc
       Namespace        : k8s-project

6. Verify
kubectl get applications -n argocd
kubectl get pods,svc,ingress -n k8s-project
